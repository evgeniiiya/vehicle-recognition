# Тема 24. Классификация наземных транспортных средств по типу кузова

Сервис, который по загруженной фотографии определяет тип наземного транспортного средства.

## О проекте

Годовой проект магистерской программы «Искусственный интеллект».

**Цель.** Собрать датасет изображений наземных транспортных средств и обучить нейронную сеть, которая определяет тип кузова или транспортного средства по фото.

**Результат.** Веб-сервис или телеграм-бот: пользователь загружает изображение и получает предсказанный класс.

### Описание этапов

1. **Постановка задачи.** Фиксация темы, предварительных классов и формата входных данных; согласование плана с куратором.
2. **Сбор данных и EDA.** Поиск открытых источников, проверка условий использования и качества разметки. Анализ распределений классов, характеристик изображений и ракурсов, визуализация и формулирование выводов. Сбор первоначальной выборки; дальнейшее пополнение — по результатам анализа.
3. **Подготовка данных.** Приведение к единому формату, удаление дубликатов и повреждённых файлов, унификация меток, работа с дисбалансом. Разбиение на train/val/test без попадания фотографий одного объекта и дублей в разные части выборки.
4. **Базовая модель.** Дообучение предобученной нейросети, выбор метрик и фиксация базового качества на валидационной выборке.
5. **Разработка сервиса.** Работающий API на FastAPI. Пользовательский интерфейс в виде сайта или телеграм-бота и его доработка — во втором семестре.
6. **Улучшение модели.** Аугментации, подбор гиперпараметров, расширение и очистка данных, сравнение архитектур и работа с проблемными классами.
7. **Оценка качества и воспроизводимость.** Выбор настроек по валидационной выборке. MLflow, логирование лучшей модели и артефактов, итоговые метрики на тестовой выборке, матрица ошибок и анализ устойчивости к условиям съёмки.
8. **Тестирование и доработка.** Проверка сервиса на пользовательских фотографиях, исправление ошибок обработки запросов, подготовка инструкций запуска.
9. **Отчёт и защиты.** Презентация промежуточных результатов в январе; итоговый отчёт, презентация, демонстрация и оформление репозитория.
